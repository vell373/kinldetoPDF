## 1. プロジェクト概要

このプロジェクトは、Kindle Cloud Reader（Web版）で読む書籍をスクリーンショットで自動キャプチャし、PDFに変換するChrome拡張機能を開発するものです。

### 1.1 背景

DRM（デジタル著作権管理）付きのKindle本をDRM解除なしでPDF化したいというユーザーニーズに対応します。スクリーンショット自動化とPDF変換により、シンプルで使いやすいソリューションを提供します。

### 1.2 目標

- 個人用途でKindle本を簡単にPDF化できる環境を提供する
- 複雑な設定やDRM解除ツール不要でユーザーが実行可能にする
- ブラウザベースの実装により、環境依存性を最小化する

## 2. 機能要件

### 2.1 主要機能

#### 2.1.1 Kindle Cloud Readerの自動スクリーンショット

- 「スクショ開始」ボタンでスクリーンショット自動化を開始
- 指定したページ数分、自動でページめくりとスクリーンショットを繰り返す
- スクリーンショット中止ボタンで任意のタイミングで停止可能
- スクリーンショット中は進捗表示（現在ページ数/合計ページ数）を更新

#### 2.1.2 PDF生成

- スクリーンショット画像を自動的にPDFに変換
- PDFに書籍のメタデータ（タイトル、作者名など）を埋め込み
- ユーザーが指定ファイル名でダウンロード可能

#### 2.1.3 ポップアップUIとコントローラー

- 拡張機能アイコンをクリックするとポップアップUIが表示
- ページ開始位置、ページ終了位置を入力フィールドで指定
- スクリーンショット実行中は、ロードスピナーで進捗を表示
- エラー時は警告メッセージを表示

### 2.2 UI/UX要件

- ポップアップサイズ：幅300px、高さ400px
- 入力フィールド：開始ページ、終了ページ（デフォルト値：1ページ目から最後まで）
- ボタン：「スクショ開始」「中止」「PDFダウンロード」
- 進捗表示：「スクリーンショット中... (25/100)」の形式

### 2.3 非機能要件

- パフォーマンス：100ページのスクショ→PDF変換が3分以内に完了
- 互換性：Chrome 90以上、Edge 90以上対応
- ローカル処理：全てのスクリーンショット・PDF変換をローカルで実行、サーバーへの送信なし

## 3. 技術スタック

### 3.1 開発環境

| 項目 | 技術・フレームワーク |
|------|------------------|
| 言語（UI） | HTML5 + CSS3 + JavaScript (ES6+) |
| スクリーンショット | Chrome Extensions API (chrome.tabs.captureVisibleTab) |
| PDF生成 | jsPDF + html2canvas |
| バンドリング | webpack / esbuild（最小化） |

### 3.2 外部ライブラリ

| ライブラリ | 用途 | バージョン |
|----------|------|---------|
| jsPDF | PDF生成 | 2.5.1 |
| html2canvas | DOM要素の画像化 | 1.4.5 |

### 3.3 Chrome Extensions API 使用

- `chrome.tabs.captureVisibleTab()`：アクティブタブのスクリーンショット取得
- `chrome.tabs.sendMessage()`：コンテンツスクリプトとの通信
- `chrome.downloads.download()`：PDF ファイルのダウンロード
- `chrome.runtime.onMessage()`：メッセージ受信ハンドラー

## 4. アーキテクチャー

### 4.1 ファイル構成

```
kindle-to-pdf-extension/
├── manifest.json                    # 拡張機能マニフェスト
├── popup.html                       # ポップアップUI
├── popup.js                         # ポップアップロジック（バックグラウンドスクリプト呼び出し）
├── popup.css                        # ポップアップスタイル
├── background.js                    # バックグラウンドスクリプト（メインロジック）
├── content.js                       # コンテンツスクリプト（ページ情報取得）
├── utils.js                         # ユーティリティ関数
├── icons/                           # 拡張機能アイコン（16x16, 48x48, 128x128）
└── README.md                        # 使用方法・開発ドキュメント
```

### 4.2 モジュール設計

#### 4.2.1 manifest.json

- 拡張機能のメタデータ定義
- 権限定義：tabs, activeTab, downloads, scripting
- 対応URL：https://read.amazon.com, https://read.amazon.co.jp

#### 4.2.2 popup.html / popup.css / popup.js

- ユーザーインターフェース
- 入力フィールド：開始ページ、終了ページ
- ボタンと進捗表示
- バックグラウンドスクリプトへのイベント送信

#### 4.2.3 background.js

- メインロジック：スクリーンショット自動化
- ページめくり操作とスクリーンショット連鎖
- 画像配列のメモリ管理
- PDF生成と Chrome API によるダウンロード

#### 4.2.4 content.js

- Kindle Cloud Reader の DOM 操作
- ページめくりボタンの検出・クリック
- ページ情報（タイトル、現在ページ数など）の抽出
- バックグラウンドスクリプトとの双方向通信

#### 4.2.5 utils.js

- ユーティリティ関数（PDF生成ロジック等）
- 画像→PDF変換の共通処理
- メタデータ処理

## 7. 制約事項・考慮事項

### 7.1 法的制約

- 個人用途でのスクリーンショット取得は著作権法の「私的使用範囲」内
- 取得したPDFの配布・販売は違法
- Amazon利用規約を遵守すること

### 7.2 技術的制約

- Chrome Manifest V3 の制限：background.js の実行時間上限
- メモリ管理：大量の画像をメモリに保持することで、ブラウザのクラッシュリスク
- ブラウザのスクリーンショット API の制限：特定タブへのアクセス要件

### 7.3 使用環境の要件

- Chrome 90 以上（または Edge 90以上）
- Kindle Cloud Reader へのログイン完了
- 十分なディスク空き容量（PDF出力用）

## データフロー図

```
ユーザー入力（popup.js）
    ↓
background.js へイベント送信
    ↓
content.js が Kindle ページ内容を取得
    ↓
スクリーンショット（chrome.tabs.captureVisibleTab）
    ↓
画像配列を保持（メモリ管理）
    ↓
ページめくり（content.js → 次ページボタンをクリック）
    ↓
ループ終了後、jsPDF + html2canvas で PDF 生成
    ↓
chrome.downloads.download() でダウンロード
```
