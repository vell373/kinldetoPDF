# Kindle to PDF Chrome 拡張機能

Kindle Cloud Reader （Web版） で読む書籍を自動スクリーンショットして PDF に変換する Chrome 拡張機能です。

## 概要

DRM（デジタル著作権管理）付きの Kindle 本を、複雑な設定やツール不要で PDF に変換できます。Kindle Cloud Reader のページをスクリーンショット自動化し、生成した画像を PDF に変換してダウンロードできます。

**個人用途での使用を想定しています。** 著作権法の私的使用範囲内でのご利用をお願いします。

## 要件

- Chrome 114 以上（Side Panel API対応）
- Kindle Cloud Reader へのログイン（read.amazon.com または read.amazon.co.jp）
- インターネット接続

## インストール方法

### 1. Chrome 開発者モード有効化

1. Chrome を開いて `chrome://extensions/` にアクセス
2. 右上の **「デベロッパーモード」** をオンに切り替え

### 2. 拡張機能をロード

1. **「パッケージ化されていない拡張機能を読み込む」** をクリック
2. このプロジェクトのルートディレクトリを選択
3. 拡張機能がロードされます

### 3. ロードされたことを確認

- `chrome://extensions/` で「Kindle to PDF」が表示されていることを確認
- エラー表示がないことを確認

## 使用方法

### 基本的な手順

1. **Kindle Cloud Reader でページを開く**
   - https://read.amazon.com にアクセス
   - キャプチャしたい書籍を開く

2. **拡張機能を起動**
   - Chrome ツールバーの拡張機能アイコンをクリック
   - サイドパネルが表示されます

3. **キャプチャ範囲を指定**
   - **開始ページ**: キャプチャを開始するページ番号
   - **終了ページ**: キャプチャを終了するページ番号
   - **ファイル名**: PDF ファイルの名前（拡張子なし）

4. **「スクショ開始」をクリック**
   - 進捗バーが表示されます
   - 指定したページ範囲が自動でスクリーンショットされます

5. **PDF がダウンロード**
   - すべてのページのキャプチャ完了後、自動的に PDF が生成されてダウンロードされます
   - ファイル名は指定した名前で保存されます

### 中断

- キャプチャ中に「中止」ボタンをクリックすると停止します
- その時点でのスクリーンショット画像は破棄されます

## 機能詳細

### 自動スクリーンショット
- Kindle Cloud Reader のページを自動でキャプチャ
- 指定ページ数分、自動でページめくりと連続撮影

### PDF 生成
- スクリーンショット画像を自動的に PDF に変換
- 元の書籍のアスペクト比を保持して PDF サイズを計算
- JPEG 品質 80% で最適化（ファイルサイズとタイトを両立）

### サイドパネル UI
- Chrome のサイドパネルで表示
- 幅 320px、スクロール可能
- リアルタイム進捗表示
- デバッグログ表示機能

## パフォーマンス

| ページ数 | 推定時間 |
|---------|---------|
| 5 ページ | 約 20 秒 |
| 10 ページ | 約 40 秒 |
| 50 ページ | 約 3 分 |
| 100 ページ | 約 6 分 |

※ ネットワーク速度、Kindle サーバーの応答速度により変動します

## トラブルシューティング

### 「Kindle Cloud Reader ページを開いてください」と表示される

**原因**: Kindle Cloud Reader 以外のページで拡張機能を使用している

**解決方法**:
1. https://read.amazon.com または https://read.amazon.co.jp を開く
2. 書籍を開く
3. 再度スクショ開始をクリック

### スクリーンショットが真っ黒に見える

**原因**: ページロード完了前にスクリーンショットが取得された

**解決方法**:
1. ページが完全に読み込まれるまで待つ
2. 再度「スクショ開始」をクリック
3. ネットワークが遅い場合は、待機時間を増やすことを検討

### ページめくりが動作しない

**原因**: Kindle Cloud Reader の DOM 構造が変更された

**解決方法**:
1. https://read.amazon.com で DevTools を開く（F12）
2. 「次ページ」ボタンのセレクターを確認
3. `content.js` の `clickNextPageButton()` 関数を更新

### PDF ダウンロードが開始されない

**原因**: `downloads` 権限がない、または Blob URL 生成エラー

**解決方法**:
1. `manifest.json` で `"permissions": ["downloads"]` が含まれていることを確認
2. Chrome の ダウンロード設定で、ダウンロード先フォルダが設定されていることを確認
3. ブラウザコンソール（DevTools）でエラーメッセージを確認

## 制約事項

### 法的制約

- **個人用途のみ**: 個人的な読書用途に限ります
- **配布禁止**: 生成した PDF の配布・販売は著作権侵害です
- **利用規約遵守**: Amazon Kindle 利用規約を遵守してください

### 技術的制約

- **Chrome 114 以上**: Side Panel API 必須
- **Kindle Cloud Reader のみ対応**: Kindle デスクトップアプリ等には未対応
- **最大 500 ページ**: 一度のキャプチャで最大 500 ページまで（メモリ制限）
- **ページ範囲指定のみ**: 複数ページ範囲の同時キャプチャ未対応

## デバッグ方法

### サイドパネルのコンソール表示

1. `chrome://extensions/` を開く
2. Kindle to PDF の詳細を展開
3. 「Service Worker を検査」をクリック
4. DevTools コンソールにログが表示されます

### ログ出力

サイドパネルの「ログ」セクションに、キャプチャ進捗のリアルタイムログが表示されます。

## よくある質問（FAQ）

### Q. 日本語版 Kindle に対応していますか？

**A.** はい。`https://read.amazon.co.jp/*` にも対応しています。

### Q. 複数冊を同時にキャプチャできますか？

**A.** いいえ。一度に一冊のみキャプチャできます。複数冊の場合は、順次キャプチャしてください。

### Q. PDF のテキスト検索（OCR）は可能ですか？

**A.** いいえ。現在のバージョンではテキスト抽出 OCR に未対応です。画像ベースの PDF となります。

### Q. スクリーンショット品質を変更できますか？

**A.** はい。`background.js` の `captureScreenshot()` 関数内の `quality` 値（現在 80）を調整できます。
