# Kindle to PDF Chrome 拡張機能

Kindle Cloud Reader （Web版） で読む書籍を自動スクリーンショットして PDF に変換する Chrome 拡張機能です。
AI（Claude / OpenAI / Gemini）によるテキスト文字起こし機能も搭載しています。

## 概要

Kindle Cloud Reader のページを自動スクリーンショットし、画像 PDF に変換してダウンロードできます。
オプションで AI API を使ってページのテキストを文字起こしし、Markdown としてダウンロードすることもできます。

**個人用途での使用を想定しています。** 著作権法の私的使用範囲内でのご利用をお願いします。

## 要件

- Chrome 114 以上（Side Panel API 対応）
- Kindle Cloud Reader へのログイン（read.amazon.com または read.amazon.co.jp）
- インターネット接続
- 文字起こし機能を使う場合：Claude / OpenAI / Gemini のいずれかの API キー

## インストール方法

### 1. Chrome 開発者モード有効化

1. Chrome を開いて `chrome://extensions/` にアクセス
2. 右上の **「デベロッパーモード」** をオンに切り替え

### 2. 拡張機能をロード

1. **「パッケージ化されていない拡張機能を読み込む」** をクリック
2. このプロジェクトの `src/` ディレクトリを選択
3. 拡張機能がロードされます

### 3. ロードされたことを確認

- `chrome://extensions/` で「Kindle to PDF」が表示されていることを確認
- エラー表示がないことを確認

## 使用方法

### 基本的な手順

1. **Kindle Cloud Reader でページを開く**
   - https://read.amazon.com にアクセス
   - キャプチャしたい書籍を開く

2. **拡張機能を起動**
   - Chrome ツールバーの拡張機能アイコンをクリック
   - サイドパネルが表示されます

3. **設定を確認**（折りたたみ可能な「設定」セクション）
   - **終了ページ**: キャプチャを終了するページ番号（省略で自動検出）
   - **ファイル名**: PDF ファイルの名前（拡張子なし）
   - **開き方向**: 左開き（洋書・横書き） / 右開き（漫画・縦書き）
   - **文字起こし AI**: Claude / OpenAI / Gemini を選択（文字起こし機能を使う場合のみ）
   - **API キー**: 選択した AI プロバイダーの API キー（ブラウザセッション中のみ保持）
   - **モデル名**: 使用するモデルを選択または追加

4. **「スクショ開始」をクリック**
   - 進捗バーが表示されます
   - 現在表示中のページから指定ページ数分、自動でスクリーンショットされます

5. **「終了してプレビュー」をクリック**
   - プレビューページが別タブで開きます

6. **プレビューページで操作**
   - **画像プレビュータブ**: キャプチャした画像の一覧表示・並び替え・削除
   - **「PDF をダウンロード」**: PDF ファイルを生成してダウンロード
   - **文字起こしタブ**: AI による全ページのテキスト認識
   - **「Markdown をダウンロード」**: 文字起こし結果を Markdown ファイルとして保存

### 中断・再開

- キャプチャ中に **「一時停止」** ボタンをクリックすると一時停止できます
- 再度クリックすると再開します
- **「終了してプレビュー」** をクリックすると、その時点のスクリーンショットでプレビューへ進みます

## 機能詳細

### 自動スクリーンショット

- Kindle Cloud Reader のページを自動でキャプチャ
- 現在開いているページから開始し、指定ページ数分を自動でページめくり・連続撮影
- 終了ページ省略時は重複フレーム検知で自動終了

### プレビュー操作

- サムネイル一覧でキャプチャ結果を確認
- **クリック**で拡大表示
- **ドラッグ&ドロップ**でページ順を並び替え
- **×ボタン**で不要なページを削除

### PDF 生成

- スクリーンショット画像を自動的に PDF に変換
- 元の書籍のアスペクト比を保持して PDF サイズを計算
- JPEG 品質 80% で最適化（ファイルサイズと画質を両立）

### AI 文字起こし

対応プロバイダーと Vision モデルを使ってページ画像からテキストを抽出します。

- **Claude**: `claude-opus-4-7` など Anthropic の Vision 対応モデル
- **OpenAI**: `gpt-4o` など OpenAI の Vision 対応モデル
- **Gemini**: `gemini-2.0-flash` など Google の Vision 対応モデル

文字起こし結果は Markdown 形式でダウンロードできます。

### モデル管理

- プロバイダーごとに複数のモデル名を登録・削除できます
- 入力欄にモデル名を入力して「追加」ボタンで追加
- 選択中のモデルを「選択中を削除」ボタンで削除
- 登録したモデル一覧は保存されます（API キーは保存されません）

## トラブルシューティング

### 「Kindle Cloud Reader ページを開いてください」と表示される

**原因**: Kindle Cloud Reader 以外のページで拡張機能を使用している

**解決方法**:
1. https://read.amazon.com または https://read.amazon.co.jp を開く
2. 書籍を開く
3. 再度スクショ開始をクリック

### スクリーンショットが真っ黒に見える

**原因**: ページロード完了前にスクリーンショットが取得された

**解決方法**:
1. ページが完全に読み込まれるまで待つ
2. 再度「スクショ開始」をクリック

### ページめくりが動作しない

**原因**: Kindle Cloud Reader の DOM 構造が変更された

**解決方法**:
1. https://read.amazon.com で DevTools を開く（F12）
2. 「次ページ」ボタンのセレクターを確認
3. `content.js` の `clickNextPageButton()` 関数を更新

### PDF ダウンロードが開始されない

**原因**: `downloads` 権限がない、または Blob URL 生成エラー

**解決方法**:
1. `manifest.json` で `"permissions": ["downloads"]` が含まれていることを確認
2. Chrome のダウンロード設定でダウンロード先フォルダが設定されていることを確認
3. ブラウザコンソール（DevTools）でエラーメッセージを確認

### 文字起こしでエラーが発生する

**原因**: API キーが未入力 / 期限切れ、またはモデル名が未選択

**解決方法**:
1. サイドパネルの設定で API キーとモデル名が入力されているか確認
2. ブラウザを一度閉じると API キーはリセットされるため再入力が必要
3. 指定したモデルが選択したプロバイダーで利用可能か確認

## 技術スタック

| 項目 | 技術 |
|------|------|
| API | Chrome Extensions Manifest V3 |
| スクリーンショット | `chrome.tabs.captureVisibleTab()` |
| PDF 生成 | jsPDF 2.5.1 |
| 通信 | `chrome.runtime.onConnect()` / Port Messaging |
| コンテンツスクリプト | `chrome.scripting` |
| APIキー暗号化 | Web Crypto API（AES-GCM 256-bit） |
| APIキー保存 | `chrome.storage.session`（セッション限定） |
| 文字起こし AI | Claude / OpenAI / Gemini Vision API |

## 制約事項

### 法的制約

- **個人用途のみ**: 個人的な読書用途に限ります
- **配布禁止**: 生成した PDF の配布・販売は著作権侵害です
- **利用規約遵守**: Amazon Kindle 利用規約を遵守してください

### 技術的制約

- **Chrome 114 以上**: Side Panel API 必須
- **Kindle Cloud Reader のみ対応**: Kindle デスクトップアプリ等には未対応
- **最大 500 ページ**: 一度のキャプチャで最大 500 ページまで（メモリ制限）
- **API キーはセッション限定**: ブラウザを閉じると API キーはリセットされます

## よくある質問（FAQ）

### Q. 日本語版 Kindle に対応していますか？

**A.** はい。`https://read.amazon.co.jp/*` にも対応しています。

### Q. 複数冊を同時にキャプチャできますか？

**A.** いいえ。一度に一冊のみキャプチャできます。複数冊の場合は順次キャプチャしてください。

### Q. PDF のテキスト検索（OCR）は可能ですか？

**A.** PDF 自体はテキスト埋め込みなしの画像 PDF です。ただし「文字起こし」機能を使うと AI がテキストを認識し、Markdown ファイルとしてダウンロードできます。

### Q. スクリーンショット品質を変更できますか？

**A.** はい。`background.js` の `captureScreenshot()` 関数内の `quality` 値（現在 80）を調整できます。

### Q. API キーはどこに保存されますか？

**A.** AES-GCM 256-bit で暗号化した上でブラウザのセッションストレージに保存されます。ブラウザを閉じると自動で消去されます。ディスクには書き込まれません。
